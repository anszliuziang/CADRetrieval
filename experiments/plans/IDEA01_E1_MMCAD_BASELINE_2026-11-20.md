# E1 补测 · 冻结 MM-CAD 对照

补齐 Fusion 360 检索的学习型参照。沿用已审 E1 的 A、B、C 查询与登记 UID。A/B 共享 256 件 DeepCAD 的图库，C 使用 256 件 Fusion 360。A 有 254 条官方短描述，B/C 各有 256 条程序派生专家描述。候选取 E1 从 8-bit 命令重放并通过几何核验的实体。用 E1 的冻结清单和几何留档复核输入。

复用 G5 的 MM-CAD v2 联合权重、修复后的 STEP 输入提取器、官方归一化统计、`title: none | text: {q}` 提示、512 token 原生窗口、768 维单位向量和余弦相似度。对原始 B-Rep 和 STEP 回读实体做体积、包围盒、双向表面和有效性核验，逐件记录面和边的邻接。包围盒对应坐标之差以 E1 归一化坐标的 10⁻⁵ 为上限。候选只从实体取得特征。先核对发布的三件参考工件，再检查两域至少各一件和一条文字的首次编码。运行环境为现有的 share4 CPU 环境，OCC 特征在本地生成。原 Text2CAD 分数从已审核矩阵读取。

## 事前锁定的结果口径

- 原生窗口主表使用全部原文，逐项报告截断数。另在 Text2CAD 和 MM-CAD 都能完整读取原文的查询上重报成绩，图库固定。两个表的查询筛选只看文本 token 数和输入覆盖。
- 若有转换或嵌入失败，MM-CAD 在完整查询分母内将缺失正例计为未命中，另报所有方法在相同可用候选上的重排名次。主表只比较同批查询、同一归属 UID 和同图库。沿用 E1 的候选哈希平分规则。
- 报 R@1/5/20、MedR、逐项名次和命中数。Fusion 的 R@1 和 R@20 都保留，用固定 5,000 次配对项目／家族 bootstrap 与 S₀、S₄₈ 比较。冻结 Text2CAD 的原生分、字段平均、减背景对数分均值和 S₄₈ 分列。地址、运行退出、覆盖、原始矩阵包括在交付中。
- E1 的专家文字可含程序步骤和归一化数值。相同实体和查询使方法任务成绩可比较，B-Rep 能恢复的历史信息有限，仍需在只描述几何约束的统一短文本或独立几何标签上检验相关性。相同 77-token 文本重测需要冻结新文本后重新评分，双人几何盲评需实际人工标签。
