# E1 补测的 MM-CAD 实施审查

一位未参与实现的 Codex 审查者核验了 E1 量化重放实体、query/gallery UID、官方联合权重、归一化配置和 STEP 特征提取。结论为可以进入 CPU 实测。审查为同模型家族的暂定审查，启动后以实际产物验证。

- 两域共 512 份原重放实体均有与冻结张量和准入记录对应的路径。历史 Text2CAD 矩阵轴为 254×256、256×256、256×256。MM-CAD 原分词器预检 A/B/C 的超长条数分别为 0、7、11。Text2CAD 已完整读取原文。
- 审查指出 STEP 的回读包围盒需要单独判定，且首批模型检查要同时覆盖两个域。编码器逐件复核 10⁻⁵ 的包围盒门，批量编码前须通过三件官方参考、两域各一件及官方接口的一条文字。官方参考样本用于验证 B-Rep 塔、权重和归一化，图库邻接另从实际特征检查。
- 四项新增的定向测试与既有 E1 评价测试合计 20 项通过。第一次本地准备在导入历史掩码函数时停止。随后复用冻结向量文件指纹和原几何记录绑定，几何准备使用新目录，原失败证据保留。
