执行依据为[预注册实验文档](../plans/IDEA01_TEXT2CAD_RETRIEVAL_ACCURACY_2026-11-18.md)。GLM‑5.3 `[1m]` 完成 max 只读审查。实施会话分别收到评分、评价的文件范围，过程都触及评价入口。Codex 于北京时间 00:35 停止本任务的两个本地会话，保存草稿与真实退出，再接手修订和运行。两个会话无成功交付回执。未接线的评价草稿留在本地 runtime，未纳入部署。

## 验收发现与修订

- 初次准备器正常退出，独立哈希对账失败。排序误用了循环末尾的文本，已修复文本和 UID 的配对。初版工件留作失败证据，重新准备的两条轴通过独立对账。全部 2,368 条入选 G5 测试查询的文本和 own-positive UID 与原件一致，验证拟合集 275 条和选型集 281 条。
- 批内维度、E2 配置寻址、列表计数总和、显式 NPU 注册与复现参考检查均经修订。候选字段覆盖审计读过两个图库全部 16,971 个官方向量，结束标记和分组计数完全对齐。
- 评价端修复了背景参数键、词门与数字门的独立执行、训练 RMS 应用到排序权重、融合选型和结果序列化。测试先核冻结配置 SHA，再读取 qrels，并核对 48 条验证背景的文本指纹。测试报告固定对照、验证选定代表和预注册诊断，提供对 SUM 与验证优胜背景的配对区间。

## 本地验收

- 定向测试实跑 73 项通过，含历史评分/评价 66 项和新回归 7 项。小型前向替身验证批量 1、14、16 保持相同的 SUM，六类分组计数和总分全部满足不变量。
- 完整 CPU 合成流水线实际退出 0。验证 37 个配置，测试按已冻结的 25 个读出完成 128 个文本组和 147 条合成查询，并输出 ranks、Top-20 与配对区间。合成结果只校验程序，真实结果待正式前向后判定。
- 真实准备工件与 SHA 在 runtime 的 `prepared_local_review_v2` 和 `local_prepared_review.json`。该步读取既有标注与向量，零模型前向。独立预期轴、GLM 方案回执、草稿和停止回执保留在同一 runtime 根。

代码进入 share4 的受控 60 对认证回放。正式验证矩阵需等真实回放通过并完成独立比对。测试规模与冻结参数只在验证阶段结束后决定。
