# 命令双塔首轮训练配方

本轮先取得能用于正式选点的同源命令双塔权重。配方适用于 Text2CAD 四级和 CadTranslator 短句两个来源，每个来源单独训练。后续测试完全按已登记的整库协议评价。

| 项 | 冻结数值或规则 |
|---|---|
| T 训练轴 | 已冻结 151,454 件，每件四级各一条，共 605,816 对。 |
| CT 训练轴 | 已冻结 148,046 件，各一条完整原文。 |
| 验证轴 | 每来源 512 个登记目标和 2,048 件图库。T 四级各评一次，并按等级等权。CT 评原生短句。 |
| 初始权重 | 固定通用 `bert-large-uncased` 修订 `6da4b6a26a1877e173fca3225479512db81a5e5b`，骨干冻结。文字投影和有序命令编码器独立随机初始化。 |
| 表示 | BERT 取带掩码的最后一层均值。CAD 使用含首尾 START 的真实 x、y、flag、index 序列。按原生顺序经过三层宽 128 的时序卷积，输出 512 维。两塔向量归一化后点积。 |
| 训练目标 | 已验对称多正例集合损失，温度 0.05。正例由本库逐条直接登记得到。同文多件可以同时为正。每批计算两方向损失、真实负例和跨 UID 的已知正例计数。 |
| 更新规则 | 单卡 batch 32，最后合法小批照常更新。每条训练配对按固定种子打乱后恰好曝光一遍。AdamW，恒定学习率 0.0003，权重衰减 0.01，梯度范数裁剪 1.0。验证编码批量 32。 |
| 窗口 | BERT 窗口 512 token，训练使用分词器原生截断，保留末尾 `[SEP]` 并保存实际曝光数。验证采用完整原文，超窗记失败，分母保留。文本批右侧补齐至 64 的倍数以控制 910A 编译形状，所有补齐位置均受注意力与池化掩码约束。 |
| 设备与精度 | 优先 910A，FP32，`ACL_PRECISION_MODE=must_keep_origin_dtype`，单卡。首轮种子 17。种子 29 和 43 的同配方复跑另登记。 |
| 首轮检查点 | 每来源一整轮末尾是本轮唯一候选。记录实测验证 R@20 和全部候选覆盖。随后若按同一方案完成多个候选，按预登记验证 R@20 选点，并列取早。 |
| 运行上限 | CT 最多 1 卡小时，T 最多 2 卡小时，含装载、训练和验证。到限保留退出码、实际步数和日志。 |

训练前验证官方档案指纹、原清单及完整训练和验证无交集，并逐轴核对候选特征。共用 CAD 特征库包含未打分的测试候选，校验其整体指纹后仅向模型提供训练与验证行。评价程序只有验证查询和验证图库。产出日期、完整代码 SHA、权重 SHA、词表、输入指纹、真实退出、训练曝光和独立的验证评价都随证据保存。正式测试查询、正例及评分的首次接触另登记。

## 910A 首次执行与算子核验

CT 首轮运行在冻结 BERT 编码完成后、首次优化器更新前退出 1。CANN 以 `Conv2D` 实现该 `Conv1d`，在 `must_keep_origin_dtype` 下拒绝 FP32 输入。保存空更新账本、实际退出、原始日志与配置。据此可使用显式的 `--command-convolution linear` 做验证。它将原卷积的五行窗口与同一权重相乘，保持参数布局、输入填充、随机初始化和其余训练配方。该选项默认关闭，实际运行记录采用的算子实现。

910A 的 CPU 对照先证实新增入口缺失能被测试发现，再以相同参数逐项验证原生卷积和矩阵实现的输出及梯度。NPU 验证使用 CT 冻结训练清单中种子 17 的首个 32 件批次，并比较 CPU 原生路径、NPU FP32 前向、损失、参数梯度和真实更新。训练开销探针、正式整轮及权重各自结算。
