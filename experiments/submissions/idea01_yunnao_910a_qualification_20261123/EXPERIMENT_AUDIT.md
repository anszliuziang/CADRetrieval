# 开发辨认实验的复核记录

复核覆盖已发布检查点在两个工程开发家族的表现。审查员与执行者为同模型家族，语义判定保留为暂定。确定性复算按远端保存的分数、独立几何记录和实际退出核对。

| 核查 | 审查结果 |
|---|---|
| 几何真值 | 题目由参数构造。独立 OpenCASCADE 重放量测了形状、尺寸、相对缺口距离和同件历史等价性；评分阶段核对固定的题目和 160 条历史的内容哈希。 |
| 分数口径 | 两个生成器用各自原生目标的对数概率总分。命令双塔用两个冻结检查点的原有余弦读出，文本骨干和头的精度按原记录。 |
| 覆盖与退出 | 四种实际打分的学习方法各有 320 个展示和 1,280 个主分数。四格得分和实际退出原件经归档逐 SHA 核验，复算按保存的双件双句分数进行。 |
| 指标 | 每件选自己描述、反向选件、四格差和并列独立复算。每对补记 $G$、$G^{swap}$ 和条件标签互换参照 $N=(G+G^{swap})/2$。 |
| 论文主张 | 两个家族和模板化描述用于开发证据。分开列出易题、固定 CAD 选句、固定句选 CAD 和八展示联合指标。 |
| 评测类型 | 合成构形上的独立可量测几何真值。粗孔形易题还伴随程序长度和几何差异。 |

初审指出三处证据缺口。原布局检查使用了保存的差值和布尔标记。补查从 32 条批分与其逐项分直接重算，核对候选及文本有效输入，得到 1 次单件选择变化和 1 次双件严格判定变化。原始主要结果使用逐项分。HierCAD 的 1,280 个分数另与固定的文本、目标序列、token 计数及分段记录逐项连接。复算同时补齐三路对照的逐对判定，并要求报告中的分组和指标键精确对应。

命令双塔的保存分数按固定的四格顺序记录。轴身份根据检查点哈希、评分器核验的有效输入和输出顺序复查。原件没有独立的逐格嵌入副本，复算范围为已保存的四格分和对应题目。

Text2CAD 的专项复核从固定的 BERT token、CAD 行、flag、index 和掩码重新构建了 1,280 个单项的输入和目标指纹，并核对了 16 条历史回放及 60 个批形状复算分。超时前的 80 条完整展示与最终文件对应的 80 行逐字节一致，最终有 320 个唯一展示。前向在 NPU 按 FP32 执行，原评分核将 logits 取回远端 CPU，按 FP32 计算对数概率和 FP64 加总。CPU 整模型前向的对照未过等价门。

已核的原件和检查点见 [运行与结果记录](RUNTIME_AND_BINDING_RESULTS.md)。
